# PR 006 — API base, OpenAPI e cliente TypeScript

## Contrato publicado

A API possui prefixo global `/api/v1`. Esta PR publica somente a identidade técnica necessária para validar a fundação:

```text
GET /api/v1
GET /api/v1/openapi.json
```

`GET /api/v1` responde:

```json
{
  "nome": "Vyntra Omnichannel",
  "versao_api": "v1"
}
```

Não existe endpoint de domínio fictício. Saúde, correlação e logs estruturados pertencem à PR 007 e não foram antecipados. A interface HTML do Swagger permanece desativada; somente o JSON revisável é servido.

## Erros canônicos

Toda rota da API responde falhas no formato:

```json
{
  "codigo": "RECURSO_NAO_ENCONTRADO",
  "mensagem": "O recurso solicitado não foi encontrado."
}
```

O código é estável e escrito em português. O filtro central converte erros HTTP comuns e substitui falhas desconhecidas por `ERRO_INTERNO`, sem devolver stack, token, payload externo ou a mensagem da exceção. `correlacao_id` será acrescentado pela PR 007 sem quebrar os campos atuais.

Entradas futuras atravessam `ValidationPipe` com allowlist, rejeição de propriedades desconhecidas e transformação automática desligada. Controllers continuam responsáveis somente por transporte e delegação.

## Geração do cliente

O contrato é gerado dos controllers NestJS e alimenta `packages/api-client`:

```text
controller + DTO
  ↓
apps/api/openapi/openapi.json
  ↓
packages/api-client/src/gerado
```

Comandos:

```text
pnpm gerar:contratos
pnpm verificar:contratos
```

O pacote exporta a operação `obterInformacoesApi`, os tipos de resposta/erro, o cliente compartilhado e uma fábrica de cliente. Web e mobile devem importar esse pacote; não devem copiar DTOs ou enums.

Arquivos sob `src/gerado` não são editados manualmente e ficam fora do lint autoral. Eles ainda passam pelo compilador TypeScript. O pacote usa resolução `Bundler`, compatível com Vite e Metro, e desliga `exactOptionalPropertyTypes` somente nessa fronteira gerada porque o emissor representa opcionais externos como `T | undefined`. Código autoral do restante do monorepo mantém as guardas estritas.

## Verificações

Os testes comprovam:

- resposta e versão em `/api/v1`;
- 404 canônico para rota desconhecida;
- ocultação de mensagem e stack em falha interna;
- OpenAPI JSON com `operationId` estável;
- ausência de interface HTML de documentação;
- regeneração determinística do contrato e do SDK;
- compilação do cliente gerado com TypeScript 6;
- auditoria de dependências sem nova exceção de vulnerabilidade.
