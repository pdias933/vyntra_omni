# PR 096C — Correção do desafio MFA no console web

## Objetivo

Corrigir o console para reconhecer o erro canônico `MFA_NECESSARIO` no formato direto devolvido pelo cliente OpenAPI. O formato encapsulado anteriormente tratado continua aceito por compatibilidade. Não há mudança de contrato, autenticação, segredo ou schema.

## Comportamento

Senha correta de conta privilegiada sem segundo fator recebe `403 MFA_NECESSARIO`. O console preserva identificador e senha somente em memória, abre a etapa do código TOTP/recuperação e não exibe mensagem genérica. Demais códigos continuam seguindo as mensagens e confirmações já aprovadas.

## Evidência

Aceite concluído em 2 de setembro de 2026 dentro da imagem cumulativa `pr-097`:

- teste de regressão exige leitura de `codigo` diretamente no erro do SDK;
- login público sem segundo fator retornou `403 MFA_NECESSARIO` no formato esperado;
- TOTP válido retornou `200` e a sessão web de aceite foi encerrada ao final;
- a tela pública carregou em `https://omni.up100.com.br`;
- lint, tipos, testes e build web foram aprovados;
- não houve migration nem mudança de contrato.

Effort recomendado e confirmado: `low`.

## Reversão

Restaurar a imagem web anterior remove a correção e volta a produzir a mensagem genérica para esse formato de erro. Banco, API e sessões não exigem reversão.
