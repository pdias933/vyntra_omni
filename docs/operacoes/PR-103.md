# PR 103 — composer e respostas rápidas mobile

## Escopo operacional

A entrega acrescenta rotas mobile autenticadas para respostas rápidas, modelos aprovados e envio de texto/modelo. O app persiste rascunho por conversa no SQLCipher e apresenta a folha categorizada de ações. Não há migration, dependência, mudança de schema local, envio offline, mídia ou efeito ERP.

## Antes de distribuir

1. Gerar OpenAPI/SDK e confirmar API, web e build mobile no mesmo commit.
2. Executar lint, tipos, testes, contratos, Expo, dependências, segredos e builds iOS/Android.
3. Confirmar que a build usa HTTPS, vínculo de dispositivo e chave pública corretos.
4. Exercitar revogação de sessão/aparelho antes e durante cada escrita.

## Aceite funcional

- Digitar `/` pesquisa somente respostas rápidas autorizadas e selecionar uma preenche o campo sem enviar.
- O rascunho reaparece depois de fechar e abrir a conversa e é separado por conversa.
- Com texto, a ação principal envia; vazio, abre a folha de ações categorizada.
- Falha preserva o texto e não apresenta mensagem confirmada.
- Sem conexão, o texto permanece rascunho e não nasce pendência até a PR 104.
- Fora da janela Meta, texto livre é bloqueado e somente modelo aprovado pode ser selecionado.
- Modelo exige todos os parâmetros declarados antes da confirmação.
- Anexo e ações ERP/Flow/notas sem implementação continuam desabilitados.
- Folhas mantêm funcionalidade equivalente com “Reduzir Movimento”.

## Observação e rollback

Observar somente volume, latência e códigos agregados das rotas. Não registrar rascunho, mensagem, resposta rápida, parâmetro de modelo, contato, conversa, token ou segredo do aparelho.

Reverter API e app de forma coordenada. A build anterior ignora o rascunho compatível sem apagar outras tabelas; uma build nova contra API antiga conserva o texto e apresenta falha, sem inventar envio. Não editar rascunho ou mensagem por SQL operacional.
