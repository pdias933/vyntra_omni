# PR 096A — Publicação segura do console web em staging

## Objetivo e limite

Esta entrega intermediária torna o console web já implementado acessível em:

```text
https://omni.up100.com.br
```

Ela publica o artefato web e encaminha `/api/*` para a API sob a mesma origem. Não promove staging a produção, não habilita dados reais, não configura Meta/MK, não cria usuário, não altera schema e não substitui o WAF previsto para produção.

## Topologia

```text
Internet
  └── 80/443 TCP + 443 UDP
      └── proxy Caddy (TLS, cabeçalhos e logs sanitizados)
          ├── /api/* → api:3000
          └── demais rotas → web:8080

Rede publicada de staging
  ├── proxy
  ├── web sem porta no host
  └── api + 127.0.0.1:3100 para operação local

Redes internas
  ├── PostgreSQL
  ├── Redis
  └── Garage S3
```

O navegador nunca acessa PostgreSQL, Redis ou S3. API, SSE e WebSocket permanecem sob a mesma origem do console, permitindo cookies `__Host-` seguros e evitando CORS amplo.

## DNS e TLS

Antes da implantação, os registros `A` e `AAAA` de `omni.up100.com.br` devem apontar para a VM aprovada. As portas 80 e 443 precisam alcançar exclusivamente o proxy.

Caddy obtém e renova certificado público por ACME, redireciona HTTP para HTTPS e persiste material de TLS no volume `certificados_proxy_staging`. Esse volume não é cache: removê-lo força nova emissão e pode atingir limites da autoridade certificadora. A configuração administrativa do proxy fica no volume separado `configuracao_proxy_staging`.

O processo executa como UID/GID `1000:1000`, com filesystem da imagem somente leitura, `no-new-privileges` e todas as capabilities removidas. Apenas os volumes de TLS/configuração são graváveis.

## Artefatos

- `apps/web/Dockerfile` constrói o SDK OpenAPI e o frontend a partir do lockfile, depois copia somente `dist` para a imagem final;
- `infra/staging/Caddyfile.web` entrega a SPA, usa fallback para `index.html` e cache imutável somente para assets com hash;
- `infra/staging/Caddyfile.borda` termina TLS, encaminha API e aplica HSTS, CSP, `nosniff`, bloqueio de frame, política de referência e permissões mínimas;
- `compose.staging.yaml` mantém `web` privado e publica somente `proxy` em 80/443;
- `scripts/ambiente-staging.mjs` sobe duas instâncias do worker e valida a origem pública.

## Implantação

No checkout exato da PR, com os segredos e volumes existentes:

```text
pnpm staging:validar
VYNTRA_CONFIRMAR_STAGING=STAGING_ISOLADO_SEM_DADOS_DE_PRODUCAO pnpm staging:subir
pnpm staging:smoke
pnpm staging:estado
```

O primeiro `staging:subir` pode aguardar a emissão do certificado. O smoke tenta novamente por até 30 segundos e exige:

- `200` no HTML do console;
- `200` em `/api/v1/saude/pronto` pela origem pública;
- redirecionamento permanente HTTP→HTTPS;
- HSTS, CSP e `X-Content-Type-Options`;
- API direta em loopback ainda saudável;
- PostgreSQL, Redis e S3 privados e saudáveis.

## Aceite manual

1. abrir `https://omni.up100.com.br` em navegador sem exceção de certificado;
2. confirmar a tela de login Vyntra sem erro de console;
3. autenticar somente com usuário sintético de staging;
4. abrir Atendimentos e conferir que chamadas e SSE usam `omni.up100.com.br`;
5. confirmar que o IP direto e aliases não autenticam como origem web;
6. verificar que 5432, 6379 e portas do Garage continuam fechadas externamente.

## Observação e incidentes

Monitorar expiração/renovação do certificado, respostas 5xx do proxy, falhas de upstream, reinícios e crescimento dos logs rotacionados. Logs da borda não devem conter corpo, cookie, token, query sensível ou cabeçalho de autorização.

Se o certificado não for emitido, conferir primeiro DNS `A/AAAA`, alcance externo de 80/443 e logs do proxy. Não trocar para HTTP, não desativar cookie seguro e não expor a porta 3100.

## Reversão

1. parar `proxy` e `web`, fechando 80/443;
2. manter os volumes `certificados_proxy_staging` e `configuracao_proxy_staging`;
3. restaurar a composição anterior, preservando API, workers e dados;
4. repetir o smoke privado da API;
5. investigar antes de republicar.

Não há migration nem dado de negócio a reverter.
