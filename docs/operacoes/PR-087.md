# PR 087 — lista web de atendimentos

## Implantação

- aplicar a migration aditiva `20260901014000_marcador_leitura_web` antes da nova API;
- implantar API e web do mesmo commit e regenerar o SDK OpenAPI;
- o índice pessoal nasce vazio e não altera mensagem, conversa ou atendimento;
- o filtro é aplicado no PostgreSQL depois de resolver as filas autorizadas.

## Aceite

1. Cada usuário recebe somente atendimentos de filas autorizadas.
2. `Meus`, `Pendentes`, `Não lidos`, `SLA`, `Expirando` e `Em automação` aparecem uma única vez.
3. Trocar filtro executa a consulta correspondente no banco.
4. Mensagem/evento confirmado atualiza e reordena pela atividade sem botão ou horário de atualização.
5. Identidade secundária é mascarada; nenhum identificador externo técnico aparece.
6. Lista vazia e indisponibilidade possuem estados distintos.
7. “Reduzir Movimento” preserva a ordem e remove a transição visual.

## Reversão operacional

A aplicação anterior ignora a nova tabela. Reverter imagens preserva marcadores já criados; não remover a migration durante o rollback.
