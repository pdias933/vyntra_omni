# Dependências — PR 013

Nenhuma dependência foi adicionada.

Argon2id usa `node:crypto` disponível na linha Node 24 fixada pelo repositório. Isso evita módulo nativo externo, instalação pós-build e nova cadeia de manutenção. A API é experimental no runtime atual; por isso Node permanece limitado a `>=24.15 <25`, versão/imagem são fixadas, hash segue formato próprio validado e os testes exercitam criação e verificação. Alterar a linha do Node exige revalidar contrato, parâmetros, desempenho e compatibilidade dos hashes antes do deploy.

Cookies são serializados internamente em contrato mínimo fechado; não foi incluído parser genérico. Prisma/PostgreSQL continuam como autoridade de credencial, sessão, rotação, tentativas e auditoria.
