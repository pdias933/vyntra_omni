# PR 011 — dependências

Nenhuma dependência foi adicionada. Usuário, perfil, catálogo de permissões, fila e vínculos de escopo usam apenas Prisma 7 e PostgreSQL já aprovados.

Os estados e códigos são enums persistidos para impedir texto livre e divergência de vocabulário. Constraints, chaves estrangeiras restritivas e índices são recursos nativos do PostgreSQL; não foi introduzido provedor de identidade, biblioteca RBAC ou cache de autorização antes dos PRs correspondentes.
