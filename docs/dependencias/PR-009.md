# PR 009 — dependências

Nenhuma dependência foi adicionada. A entrega reutiliza Prisma 7, o adaptador `pg`, PostgreSQL e os mecanismos de sanitização já aprovados na PR 008.

A sequência global é nativa do PostgreSQL (`BIGSERIAL`) e a atomicidade usa a transação interativa já oferecida pelo Prisma. Não foi introduzido broker, SDK de eventos ou biblioteca de unidade de trabalho.
