O app passa a consumir `@vyntra/api-client` do próprio workspace. Não existe segundo contrato HTTP e nenhum SDK Meta/MK entra no cliente.

React Navigation introduziu `query-string → decode-uri-component@0.2.2`, afetado por `GHSA-vcc3-ghjq-m6fr`. O override estrito para `decode-uri-component@0.5.0`, versão corrigida e compatível com a API usada, remove o advisory sem exceção. Os novos caminhos oficiais `@expo/vector-icons` e `expo-camera` alcançam o mesmo `xcode → uuid@7.0.3` já limitado desde a PR 002; a allowlist foi ampliada somente para esses ancestrais exatos, conserva versão, sufixo, metadados e prazo de 29 de setembro de 2026 e agora aponta para esta análise atualizada.

## Limites de segurança

Camera e autenticação local são chamadas somente após ação/abertura correspondente. Access token continua apenas em memória; refresh, instalação, dispositivo e segredo de vínculo continuam no SecureStore com backup Android desativado. O QR e seu comprovante ficam apenas no estado em memória até confirmação, cancelamento ou expiração.
