# PR 096A — Dependência de borda e servidor web

## Decisão

A entrega usa a imagem oficial `caddy:2.11.4-alpine`, fixada simultaneamente por versão e digest multiarch:

```text
docker.io/library/caddy:2.11.4-alpine@sha256:5f5c8640aae01df9654968d946d8f1a56c497f1dd5c5cda4cf95ab7c14d58648
```

A mesma base mínima serve o conteúdo estático em rede privada e termina TLS no proxy. Não foi adicionada dependência JavaScript nem módulo Caddy de terceiros.

## Motivo

Caddy oferece servidor de arquivos, reverse proxy, suporte nativo a WebSocket/SSE e HTTPS automático no binário oficial. Isso evita coordenar Nginx, Certbot e um job de renovação separado para o primeiro staging público.

Referências primárias:

- [imagem oficial Caddy](https://hub.docker.com/_/caddy);
- [HTTPS automático](https://caddyserver.com/docs/automatic-https);
- [padrão oficial para SPA + API](https://caddyserver.com/docs/caddyfile/patterns);
- [reverse proxy](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy).

## Manutenção, licença e cadeia de suprimentos

- Caddy é mantido pelo projeto Caddy e a imagem é uma Docker Official Image;
- o código é licenciado sob Apache-2.0;
- a tag exata foi publicada para múltiplas arquiteturas e o digest impede troca silenciosa;
- o Dockerfile fixa também frontend Node, pnpm e lockfile;
- o ciclo de atualização deve revisar release notes, digest e CVEs antes de trocar a versão;
- certificados e chaves ficam em volume da VM de staging e nunca entram na imagem ou no Git.

## Redução de risco

- processo sem root (`1000:1000`), sem capabilities e com `no-new-privileges`;
- imagem e configuração somente leitura;
- área gravável restrita aos volumes próprios do Caddy;
- painel administrativo do Caddy desativado;
- nenhum plugin externo ou API de DNS;
- logs limitados pelo driver do Compose;
- web sem porta no host e dados internos em redes separadas;
- cabeçalhos defensivos e origem HTTPS exata.

## Limites

O proxy de staging não substitui Cloudflare/WAF, rate limiting de borda, mitigação DDoS ou observabilidade de produção. A publicação direta é aceita apenas para testes com dados sintéticos/sanitizados. Produção continua dependente das PRs operacionais posteriores.
