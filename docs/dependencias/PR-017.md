# Dependências — PR 017

Nenhuma dependência foi adicionada.

O backend reutiliza `node:crypto`, Prisma/PostgreSQL, autenticação web/mobile e auditoria centrais. QR é um transporte visual do token opaco: a API não gera imagem e não incorpora biblioteca de leitura. Scanner, câmera e interface do app serão consumidores posteriores do contrato OpenAPI gerado e exigirão avaliação própria antes de acrescentar pacote nativo.

Advisory locks recebem apenas chaves internas derivadas de UUID, hash, IP ou instalação e protegem seções transacionais curtas. Redis não participa do uso único, limite, confirmação ou conclusão.
