# PR 012 — dependências

Nenhuma dependência foi adicionada. O serviço central reutiliza NestJS para injeção, Prisma 7 para projeções exatas no PostgreSQL e os contratos internos já existentes.

Não foi introduzida biblioteca RBAC, policy engine, cache Redis ou provedor de identidade. A matriz é pequena, explícita, tipada e versionada com o código; o PostgreSQL continua autoridade para usuário, perfil, ajustes e acesso de fila. Sessões reais entram em PR próprio.
