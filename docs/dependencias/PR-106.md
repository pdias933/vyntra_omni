# Dependências da PR 106

## Decisão

Nenhuma dependência foi adicionada, removida ou atualizada.

A entrega reutiliza `expo-notifications ~57.0.16`, introduzido e auditado na PR 057, o motor de sincronização, o SQLCipher e React Navigation existentes. A caixa agrupada é implementação interna em memória e não acrescenta armazenamento, analytics, SDK de provedor ou serviço remoto.

O adapter real de entrega push no backend permanece desligado até existirem credenciais, destinos e operação aprovados. Esta PR não contorna esse portão com simulador ou registro fictício.
