## Decisões de superfície

O JSON fica em `/api/v1/openapi.json`. A interface HTML do Swagger não é publicada, reduzindo dependências estáticas expostas e evitando uma superfície administrativa sem autenticação. O contrato e o cliente são regenerados por `pnpm gerar:contratos`; os arquivos gerados são versionados para tornar mudanças revisáveis.

`@nestjs/swagger` traz `swagger-ui-dist`, que possui o instalador opcional de telemetria `@scarf/scarf`. Como a interface não é usada e scripts de dependências são `default deny`, o build desse pacote é explicitamente recusado em `pnpm-workspace.yaml`. Nenhuma telemetria é executada.

Somente os plugins internos de tipos, SDK e Fetch são ativados. Integrações de registry, schemas de validação e bibliotecas de cache permanecem fora, mantendo o cliente compatível com web e React Native sem regra de negócio ou autenticação embutida.

O código emitido fica fora do lint autoral porque contém infraestrutura genérica do próprio gerador, mas permanece submetido a TypeScript e à revisão do diff. A configuração menos estrita de opcionais é limitada ao pacote gerado e documentada no contrato da PR; ela não altera a base compartilhada do monorepo.

O override de `js-yaml` força a correção do advisory `GHSA-52cp-r559-cp3m` em todos os caminhos transitivos. Não foi criada exceção temporária no scanner.
