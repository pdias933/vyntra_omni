# Dependências — PR 014

Nenhuma dependência foi adicionada.

Limite, inatividade e revogação usam Prisma/PostgreSQL e os serviços centrais já presentes. O único SQL bruto novo é `pg_advisory_xact_lock(hashtextextended(...))` parametrizado por uma chave interna derivada do UUID do usuário. Ele serializa apenas a seção curta de contagem/revogação/criação e não engloba Argon2id nem entrada dinâmica de SQL.

O lock é transacional e não é fonte de verdade: estado, expiração, motivo e auditoria permanecem no PostgreSQL. Redis não participa do limite.
