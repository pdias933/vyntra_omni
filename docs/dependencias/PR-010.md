# PR 010 — dependências

Nenhuma dependência foi adicionada. A entrega reutiliza Prisma 7, PostgreSQL e `node:crypto`, já disponível no runtime Node.js fixado pelo projeto.

UUIDs de alta entropia vêm de `randomUUID`; SHA-256 protege em repouso chaves idempotentes e tokens aleatórios de concessão. Esse hash não é usado para pesquisar CPF, telefone ou outro dado de espaço pequeno: esses casos continuam exigindo HMAC/índice protegido com chave gerenciada.

Não foi introduzido broker, biblioteca de lock distribuído ou scheduler. O PostgreSQL permanece autoridade para unicidade, versão, concessão, tentativas e recuperação.
